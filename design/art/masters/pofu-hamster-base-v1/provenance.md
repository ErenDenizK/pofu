- **File:** `pofu-hamster-base.png`, 1024 × 1536, RGBA.
- **Role:** R1, the reference for all character art (art bible §1). Chosen
  by the founder on 2026-11-01.
- **Tool:** GPT Image in ChatGPT (Pro), generated by the founder following
  prompt 1 of the [prompt library](../../../../docs/design/prompt-library.md#1-the-base-r1).
  Exact model label, final prompt text and number of generations considered:
  to be filled in by the founder.
- **References attached:** R0 concept and the character palette card
  (per prompt 1).
- **Human edits after generation:** alpha values below 6/255 (invisible
  generator noise across the empty canvas) set to 0; lossless PNG
  optimization. No pixel of the character was changed.
- **Clearance:** reverse-image search against existing hamster mascots is
